# Test 1.1 Process

## Run A

The lead-generation process was executed using human effort only.

Total measured production time:

**156.5 minutes per lead**

## Run B

The same overall process was executed using an integrated human + AI approach.

AI was used within the workflow rather than being treated as a separate production process.

Total measured production time:

**136 minutes per lead**

AI-assisted activity within Run B:

**50.5 minutes**

## Measurement Principle

The experiment measures the total time required to complete the process.

AI activity occurring within that process is therefore included in the Run B total.

This prevents double-counting AI activity.
