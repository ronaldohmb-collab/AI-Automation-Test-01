# Test 1.1 Hypothesis

## Hypothesis

If AI is integrated into an existing human-led lead-generation process, then the total end-to-end time required to produce a lead will decrease compared with a human-only process.

## Expected Outcome

Run B should require less total production time per lead than Run A.

## Measurement

The hypothesis is evaluated using:

**Time saved per lead = Run A time − Run B time**

**Efficiency improvement = Time saved ÷ Run A time × 100**

## Null Position

If AI integration does not improve end-to-end efficiency, Run B will require the same or greater total production time per lead than Run A.
