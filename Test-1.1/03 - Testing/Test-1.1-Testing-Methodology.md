# Test 1.1 Testing Methodology

## Experimental Design

The test compares two versions of the same lead-generation process.

### Run A — Control

Human-only execution.

### Run B — AI-Assisted

Human and AI execution integrated into the same workflow.

## Important Measurement Rule

Run B is measured as one integrated process.

AI-assisted time is already contained within the Run B total.

Therefore:

**Run B total = 136 minutes per lead**

The recorded AI-assisted component of:

**50.5 minutes**

must not be added to the Run B total.

## Primary Metric

Total production time per lead.

## Calculation

Run A:

156.5 minutes per lead

Run B:

136 minutes per lead

Time saved:

156.5 − 136 = **20.5 minutes per lead**

Efficiency improvement:

20.5 ÷ 156.5 × 100 = **13.1%**

## Evaluation

The test is considered to demonstrate an efficiency improvement if the integrated AI process produces a lower end-to-end production time than the human-only process.
